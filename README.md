# Rhuan Torquato — demonstração

Site estático responsivo em HTML, CSS e JavaScript, sem instalação de dependências. Abra `index.html` no navegador ou execute `python -m http.server 8080` nesta pasta e acesse http://localhost:8080.

Fotos públicas baixadas de @rhuan_torquato. Os três posts originais estão vinculados no site. Os botões de acompanhamento apontam para https://bit.ly/49WQF5g, link informado na bio. Fontes do Google Fonts, com alternativas locais em CSS.

Conteúdo demonstrativo sujeito à aprovação do profissional. Não foram inventados depoimentos, resultados, credenciais, preços ou detalhes operacionais do Método RT. Antes de publicar profissionalmente, validar textos, direitos de imagem e informações profissionais obrigatórias.
